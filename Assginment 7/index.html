JavaScript Assignment 7

Functions Level - 2

Task 1

This task simulates a shopping app scenario where a discount is applied to a product price. You create a function that takes the original price and discount amount, calculates the final price, and returns it. Concepts covered: basic function logic, parameters, return values, real-world calculations.

Task 2

This task checks whether a student has passed an exam based on their marks. The function evaluates the marks and returns "Pass" or "Fail" using conditional logic. Concepts covered: conditionals (if/else), decision-making in functions.

Task 3

This task introduces callbacks using a food delivery app example. One function places an order and then executes another function (callback) once the order is placed. Concepts covered: callback functions, function execution flow.

Task 4

This task simulates sending an OTP (One-Time Password). The main function sends the OTP and passes the value to a callback function, which then displays it. Concepts covered: callbacks with parameters, data passing between functions.

Task 5

This task demonstrates call by value behavior using a wallet balance example. The function adds money to a balance but does not change the original value outside the function. Concepts covered: primitive data types, call by value, immutability.

Task 6

This task explains call by reference using an array. An item is added to a shopping cart inside a function, and the change is reflected outside the function. Concepts covered: arrays, call by reference, mutable data structures.

Task 7

This task updates a user profile object by changing the user’s name. The change persists outside the function, demonstrating object reference behavior. Concepts covered: objects, reference types, object mutation.

Task 8

This task combines callbacks with calculations by building a simple calculator logic. The main function accepts numbers and a callback that performs the calculation and displays the result. Concepts covered: higher-order functions, callbacks with logic execution.
